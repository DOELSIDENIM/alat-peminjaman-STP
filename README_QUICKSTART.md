# 🚀 Sistem Peminjaman Alat - Quick Start

## Cara Menjalankan Aplikasi

### 1️⃣ Start XAMPP
- Buka XAMPP Control Panel
- Start **Apache** dan **MySQL**

### 2️⃣ Setup Database (Pertama Kali)
```batch
setup.bat
```

### 3️⃣ Jalankan Server
```batch
run-dev.bat
```

### 4️⃣ Buka Browser
```
http://127.0.0.1:8000
```
